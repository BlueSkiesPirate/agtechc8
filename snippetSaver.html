Project Overview

When coding a website many of us have had that moment in which we have wished we had some sort of storage for those complex functions we create that can be replicated from site to site. Let's say you created a search bar for a previous project, and now one of your newer projects also uses a search bar, wouldn't it be better to get exactly the code you already wrote and tweak it only slightly for this new code?

With Snippet saver you are able to just that, this MongoDb powered database allows users to store multiple separated pieces of code under a single snippet for those functions that require multiple files to work. Users can also add descriptions and tags to find the snippets better. On the top there is a search bar that users can take advantage off to filter the snippets by the tags they previously created, or by the titles of the snippets.

To the left of the screen there is also a section that allows users to add hyperlinks to their most used websites when coding. Let's say you found an Icon library to use on your react native project, this is coding specific, so it will be better to to add it to the dashboard rather than having it clutter your saved pages screen.

Design

When designing this app the inspiration was a control panel, which means that the user has all of the important features in the main page, so that people can conviniently access these features and can work more effectively.

Conclusion

The main features for the site are working save for the authentication system and the search bar. there is a middle line in the page that allows users to resize the results and snippet sections so that users can get a better view of what they prefer. The page is only meant for computer's since that's the enviroment in which most people code their websites. Overall the project has met my initial goals, and now I am essentially working on ways to take it to the next level.
